# Процедурные текстуры в коде

Хак того же рода, что и [меши в строке](meshformat.md): в zip не кладётся ни одной картинки,
всё строится на загрузке. Реализация — `html/js/texture.js`, шейдер-потребитель —
`planetProgram` в `objects.js` (см. [architecture.md](architecture.md#планеты-и-звёзды--трипланарный-шейдер)).

Два артефакта:

- **одна общая текстура шума** (`GenNoiseTexture`) — вход трипланарной выборки шейдера планет;
- **градиенты-рампы** (`GenRampTexture` / `GetRamp`) — полоска `N×1` пикселей, по которой
  шейдер берёт цвет поверхности индексом = смешанное значение шума («высота → цвет»).

## `MakeTexture(gl, w, h, uint8data, repeat)`

Оборачивает сырые байты (`RGBA/UNSIGNED_BYTE`, фильтр `LINEAR`) в GL-текстуру. `repeat=true`
ставит `gl.REPEAT` (нужен для tileable-шума, требует **power-of-two** размеров); `repeat=false`
— `CLAMP_TO_EDGE` (рампы `N×1`, NPOT допустим без мип-мапов).

## `GenNoiseTexture(gl, size = 64)` — многослойный value-noise

Классический шум: для каждой октавы — сетка `freq×freq` случайных чисел `-1..+1`,
между узлами — **косинус-интерполяция** (`s = (1 - cos(t·π)) / 2`), индексы сетки замыкаются
по модулю (`(i+1) % freq`), поэтому текстура **бесшовно тайлится** (шейдер читает её с
`gl.REPEAT`). Октавы `freq = 4, 8, 16` (то есть длины волны `1/4, 1/8, 1/16` от текстуры) с
амплитудой `1, 1/2, 1/4`; сумма ремапится `min..max → 0..1` и пишется в `r=g=b` (α=255).
Октаву `1/32` намеренно не берём — с ней поверхности выглядят «наждачкой». Вызывается один
раз на всю игру (в `InitPlanetRenderer`), `size` должен быть степенью двойки.

## `GenRampTexture(gl, str, width = 64)` — градиент из строки

Строка — это последовательность RGB-ключей, каждый **3 символа** в той же квантизации, что и
меши (`geometry.js`, см. [meshformat.md](meshformat.md)): `MeshCharVal(str.charCodeAt(i)) / 92`
→ `0..1` на канал (беззнаковый вариант: `n / 92`, где `n = 0..92`). Ключи раскладываются
равномерно по `0..1`, между ними линейная интерполяция в полоску `width×1` RGBA. Пример:
`' ~~'` → `' '`(n=0)=0 → R=0, `'~'`(n=92)=1 → G=B=1 → чистый cyan-ключ.

Наборы рамп лежат рядом с архетипами: `PLANET_ARCHETYPES` в `system.js` (terran, oceanic,
mars, gray-moon, rocky-tan, icy, volcanic, два газовых гиганта) и `STAR_ARCHETYPES` в
`galaxy.js` (red-dwarf, orange, sol, white, blue-white). Строки посчитаны офлайн маленьким
Python-скриптом из RGB-ключей `0..255` — вручную посимвольно не подбираются.

## `GetRamp(gl, str)` — кеш

`rampCache[str]` — N тел одного архетипа делят одну текстуру рампы. Планеты/звёзды/луны все
зовут `GetRamp(ctx.gl, arch.ramp)`, так что реальных текстур-рамп ровно столько, сколько
разных строк (≈14), независимо от числа планет.
