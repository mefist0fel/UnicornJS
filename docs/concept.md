## Тема

js13k 2026 — **Unicorns and Rainbows**.

## Игровой цикл

Небольшой прототип: **корабль — хаб**, всё остальное открывается из него. Всё рисуется одними
и теми же примитивами (сферы — звёзды/планеты, кубики — корпус/модули/снаряды/маркеры), так что
на этом проходе "игра" — навигационно-строительный скелет, на который позже повесится контент
про единорогов и радуги.

1. **Меню** (`menu_state.js`) — заголовок + "Play". Кнопка генерирует галактику ровно один раз
   (`GenerateGalaxy()`), сбрасывает конфиг корабля (`ResetShip()`) и переносит в ангар.
2. **Ангар корабля** (`ship_state.js`) — основной режим. Корабль в центре: корпус и слоты
   декодируются из **схемы-строки** текущего фрейма (`modules.js`, [shipformat.md](shipformat.md)).
   Слева секционный список: строка **Ship** (апгрейд фрейма — меняет корпус и статы: HP,
   потолки слотов), затем Weapons / Modules / Support (показаны первые `SlotCap` каждой
   категории). Выбор строки открывает конверсии с ценой в металле (граф `MODULES`); любой
   модуль может менять `shipStats` (щит → ёмкость щита, апгрейд → потолки). Здесь же **бой** —
   см. [battle.md](battle.md): враги (тоже схема-кубики) прилетают из дебаг-меню или с планеты,
   орудия стреляют сами по случайным точкам корпуса врага, ПВО сбивает ракеты. HP в 0 → меню;
   все убиты → лечимся. Кнопка `Map` (пока нет боя) ведёт на карту системы; на солнечной
   орбите ещё кнопка `Hyperjump` → карта галактики.
3. **Карта системы** (`system_state.js`) — звезда + 4-7 планет (`system.js`, кеш по индексу
   звезды). Зелёный кораблик-маркер крутится там, где игрок припаркован (внешняя орбита /
   солнце / планета). **И звезда, и планеты** выбираются как цель прыжка → `Jump` →
   `system_travel_state.js` (эффект в ship-виде: настоящий корабль + искры) → снова ангар у
   цели. Прыжок к планете с непобеждённым противником — сразу в бой. Прыжок к звезде —
   припарковались на солнечной орбите (полноценная локация, там доступен гиперпрыжок).
   `Return to ship` — назад в ангар без перемещения.
4. **Карта галактики** (`galaxy_state.js`) — сетка 5×5 звёзд + кольцо радиуса прыжка вокруг
   текущей. Открывается кнопкой `Hyperjump` с солнечной орбиты. Звезда в радиусе → зелёный
   маркер + линия + `>` (тратит гипертопливо) → `hyperjump_state.js` (эффект в ship-виде:
   настоящий корабль + радужный тоннель) → ангар на солнечной орбите новой системы.

## Ресурсы

Всё в игре — обмен ресурсов: плоский массив чисел (`res` в `resources.js`), индексируемый
`RES_MONEY` / `RES_FUEL` / `RES_METAL`, показанный строкой в HUD в правом верхнем углу.

- **Топливо** тратится на межзвёздные прыжки (`GALAXY_JUMP_FUEL_COST`). Локальные прыжки на
  планету бесплатны.
- **Металл** тратится на постройку/апгрейд модулей и фреймов корабля (`MODULES[id].cost`).
  Старт — 100, других источников на этом проходе нет (собирание ресурсов с планет убрано).
- **Деньги** — пока не тратятся (диалоги убраны); задел на торговлю.
- Статы корабля — отдельный плоский массив `shipStats` (`STAT_HP` / `STAT_WEAPONS` /
  `STAT_MODULES` / `STAT_SUPPORTS` / `STAT_SHIELD`), пересобирается из базы фрейма + вклада
  каждого установленного модуля (`RebuildShipStats`). HP-пул = `STAT_HP + STAT_SHIELD`;
  фреймы `s1/s2/s3` дают 500/900/1400 HP и растущие потолки слотов.
- Постройка не мгновенная: металл списывается сразу, модуль встаёт через `buildTime`
  (тир ~2с, корвет ~3.5с, разборка ~0.6с, смена фрейма ~5с; очередь `builds` в `modules.js`).

## Что ещё не решено

- Источник металла кроме стартового запаса (награда за бой? добыча?).
- Радиусы стрельбы и движение кораблей в бою (сейчас все стреляют, стоя на месте).
- Диалоги/торговля (полностью убраны на этом проходе).
- Арт-стайл: сферы (планеты/звёзды) уже с процедурной поверхностью — трипланарный шум +
  градиент-рампа, у газовых гигантов горизонтальные полосы (см.
  [texture.md](texture.md) и [architecture.md](architecture.md#планеты-и-звёзды--трипланарный-шейдер));
  кубики (корабли/маркеры/снаряды) — по-прежнему плоские, `meshformat` для кораблика. Что
  дальше — атмосферный ореол, кольца, нормальные модели кораблей.
- Звук (пока не подключён).
- Собственно контент про единорогов и радуги — этот проход был целиком про
  навигационно-экономический скелет.

  комментарии в коде и доки остаются на русском, см. [architecture.md](architecture.md).
- Файлы состояний — один файл на состояние, имя `xxx_state.js`, см.
  [architecture.md](architecture.md#стейт-машина).
