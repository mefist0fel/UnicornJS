# Концепт

> Статус: **черновик, не финальный**. Фиксируем направление, детали геймплея будут меняться.

## Тема

js13k 2026 — **Unicorns and Rainbows**.

## Идея (рабочая)

Маленькая 3D-солнечная система, состоящая из планет-единорогов, соединённых радугами.
Игрок перемещается между "видом системы сверху" и "видом отдельной планеты", кликая по
объектам сцены. Никакого текста-лора пока не заложено — приоритет на минимальный, но
приятный интерактивный визуал (орбитальная камера, клики по сферам, простая цветовая
палитра в духе радуги).

Жанр и точная цель (аркада / кликер / исследование) осознанно не зафиксированы — сначала
собираем технический прототип (навигация между сценами, камера, пикинг, UI), потом
надстраиваем геймплей поверх него.

## Что уже решено

- 3 состояния приложения: **меню**, **солнечная система**, **планета** — см.
  [architecture.md](architecture.md#стейт-машина).
- Навигация — 3D (орбитальная камера с ограничителями, разными для сцены системы и сцены
  планеты, см. [camera.md](camera.md)) + клики по сферам в 3D + кнопки в UI-панелях
  ([ui.md](ui.md)).
- Технические рамки: без сторонних JS-зависимостей, жёсткий бюджет по размеру (13 312 байт
  в зипе), см. [build.md](build.md).

## Что не решено

- Финальная механика геймплея (что именно делает игрок на планете/в системе).
- Арт-стайл текстур/цвета сфер (сейчас — плоские цвета, placeholder).
- Звук (в прошлом проекте использовался jsfxr; в этом прототипе пока не подключён).
- Количество планет, их различия, есть ли прогрессия/уровни.
