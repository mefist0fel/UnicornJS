# Корабль в строке

Хак того же рода, что [меши](meshformat.md) и [текстуры](texture.md): корпус корабля и
раскладка его слотов записываются одной короткой строкой. Один декодер (`DecodeShipSchema` в
`modules.js`) обслуживает и корабль игрока, и вражеские корабли.

## Формат

```
"<W><сетка W*H символов, построчно>|<пары координат вспомогательных>"
```

- **`W`** — ширина сетки, одна цифра.
- **сетка** — `W*H` символов подряд, строка за строкой. Высота `H = grid.length / W`.
  **`col → x` (лево/право), `row → z` (вперёд/назад), `row 0` = нос корабля (−z = вперёд).**
  Так что читать сетку удобно как вид сверху, где верх страницы = нос. Алфавит:
  - `.` — пусто (клетки нет)
  - `#` — корпусной кубик (косметика; позже заменится на выразительные куски)
  - `W` — слот орудия
  - `M` — слот модуля (ПВО / щит)
- Мировые координаты клетки центрированы:
  `((col - (W-1)/2), 0, (row - (H-1)/2)) * SHIP_CELL` (`SHIP_CELL = 0.55`).
- **`|<пары>`** — слоты вспомогательных кораблей (в сетку не входят, стоят вокруг). Каждый —
  две цифры `(cx, cz)` → `(x, z)`; смещение от центра в клетках = `цифра − 4` (−4..+5).
  Первые пары обычно ставят по бокам (`(-4,0)`,`(4,0)` = `0484`), дальше — за кормой.

`DecodeShipSchema(str)` → `{ w, h, cells, weapons, modules, supports }`, где `cells` — **все**
непустые клетки (нужны и для косметического корпуса, и для «объёмного» прицеливания: выстрел
берёт случайную клетку + случайную точку в её объёме `±SHIP_CELL/2`).

## Примеры

| id | схема | форма |
|----|-------|-------|
| `s1` Scout | `3.#.MWM###.#.\|1474` | 3×4: нос вперёд, 1 орудие в центре, 2 модуля по бокам (x=±), 2 вспом. слота слева/справа |
| `s2` Wing  | `5..W..M###M##W##M###M.#W#.\|0484` | 5×5 симметричная стрелка: 3 орудия по хребту (z), 4 модуля на крыльях (x=±), 2 вспом. по бокам |
| `s3` Battle | `5.W.W.M#W#MW###WM###M.###.\|048448` | 5×5: 5 орудий (2 у носа + хребет + 2 на законцовках), 4 модуля на крыльях, 3 вспом. (2 по бокам + 1 за кормой) |
| enemy Raider | `3.W.###.#.` | 3×3, 1 орудие, без вспом. слотов (нет `\|`) |
| enemy Carrier | `5.###..#W#.#####.#W#..###.` | 5×5; фрегаты спавнятся отдельно (`arch.frig`) |

## Как используется

- `modules.js`: `MODULES[MOD_FRAME_SCOUT/_WING/_BATTLE]` — модули **центрального слота** (фреймы). Установка
  такого модуля через `BuildShip(id)` меняет `currentShipId`, а `rebuildSlots()` пересобирает
  `shipSlots` из новой схемы (перенося уже построенные модули по паре `(тип, порядковый номер)`).
  `stats` каждого фрейма задаёт базовые `shipStats` — HP и **потолки** слотов по категориям
  (см. [architecture.md](architecture.md#корабль-схема--статы--слоты)).
- `ship_state.js`: `rebuildHull()` рисует по кубику на каждую `cells`, модульные визуализации
  (пушка / корвет, выбор по `SlotViz(id)` — диапазону id, не по полю) висят над клетками
  `W`/`M`. Враги (`makeEnemyShip`) — тот же декодер, красные кубики, орудия из клеток `W`.
