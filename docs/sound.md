# Звук и музыка

Задача (блок 5): финального звука пока не делаем, но нужен **первый рабочий проход** — SFX
для кнопок/выстрелов/перелётов и простая тягучая «тикающая» музыка на настроение (саспенс, а
не мелодия). Важно: **не тащить две библиотеки** — даже упакованные синтезаторы+трекеры
тяжёлые, и если уж брать, то сразу, чтобы уложиться в бюджет.

> **Статус (блок 4, срез размера):** амбиент-музыка **вырезана** — стоила ~360 Б zip и была
> самой сырой частью; `MusicStart`/`MusicStop` оставлены пустышками, чтобы колл-сайты и
> возможный возврат трека не трогали код. `Tone`/`Noise` переведены с объекта-опций на
> **позиционные аргументы** (music-only ручки `attack`/`sustain`/`at`/`bus` и `_musicBus`
> убраны, attack и «колено» decay зафиксированы). Итого проход по звуку: **−586 Б**
> (15 689 → 15 103). Ниже описание приведено к текущему коду; трекерная секция — как
> ориентир на будущее.

## Что рассматривали

| Подход | Размер (мин.) | SFX | Музыка | Замечание |
|---|---|---|---|---|
| **jsfxr** (порт sfxr) | ~1.5–2 КБ | ✅ параметрические ретро-эффекты | ✖ только one-shot | Знаком автору; но это ещё одна вкладка кода, и без трекера музыки нет. |
| **ZzFX** + **ZzFXM** | ~1 КБ + ~1 КБ | ✅ | ✅ трекер поверх того же ядра | «Одна семья», де-факто стандарт js13k. Но ZzFXM хочет свой формат песни (вложенные массивы) и внешний онлайн-трекер, чтобы её сочинить. |
| **sonant-x / Sonant Live** | ~3–6 КБ | ✅ софт-синт | ✅ полноценный трекер | Жирновато для нашего бюджета. |
| **TinyMusic** | ~1.5 КБ | ✖ | ✅ секвенсор на осцилляторах | Только ноты-строки, без синтеза перкуссии/шумов — «тик» делать нечем. |
| **Голый Web Audio, свой мини-синт** | ~1.4 КБ (наш код) | ✅ | ✅ | Один модуль, один формат, ноль зависимостей — ровно под правило проекта («пишется руками или генерируется процедурно»). |

## Решение: свой мини-синт (`html/js/sound.js`)

Правило проекта запрещает сторонние пакеты/CDN; вклеивать чужой минифицированный blob
(jsfxr/ZzFX) — против духа правила. Свой синт в стиле ZzFX закрывает **и** SFX, **и** музыку
одним файлом, форматом данных служат обычные объект-литералы (никакого трекер-DSL), и это
честно «написано руками». Цена — ~1.4 КБ в zip (замер: 14 703 → 16 075 Б до оптимизации;
блок 4 разберётся).

### Примитивы

Позиционные аргументы, без объекта-опций (ZzFX-стиль). Все вызовы — из `Sfx`/`SHOOT_SFX`
ниже; играются от `c.currentTime`, маршрут всегда `_master`.

- `Tone(type, f0, f1, decay, release, vol)` — один осциллятор с огибающей по gain
  (фикс. attack 5 мс → `vol` → «колено» `vol*0.3` за `decay` → 0 за `release`).
  `type` = `square`/`sawtooth`/`triangle`/`sine`; `f1` (falsy = без глиссандо) — цель
  экспоненциального разгона частоты к концу.
- `Noise(dur, filter, cut, cutEnd, vol)` — всплеск белого шума через `BiquadFilter`
  (`filter` = `lowpass`/`bandpass`), срез `cut → cutEnd` (falsy = без разгона),
  экспоненциальный спад gain. Импакты, «тики», вжух перелёта.

Обе одноразовые: создают узлы, планируют, сами останавливаются (`osc.stop`/`src.stop`).

### SFX-пресеты

`Sfx.{click, build, hit, explosion, jump, hyperjump, death}` и `SHOOT_SFX.{kinetic, plasma,
rocket}` (обёртка `SfxShoot(kind)` по `fireKind` из `modules.js`) — каждый пресет это 1–2
позиционных вызова `Tone`/`Noise`. Параметры подобраны на слух — заготовки, автор потом
подкрутит (в т.ч. можно прогнать через настройщик jsfxr и перенести числа руками).

### Музыка — вырезана

16-шаговый «тикающий саспенс» (2 дрона на корне+квинте с LFO-дыханием, `bandpass`-тики,
бас-удар, редкие минорные `triangle`-ноты, планировщик на `setInterval`) стоил ~360 Б и был
самой сырой частью — **удалён в блоке 4**. `MusicStart()`/`MusicStop()` остались пустыми
функциями (колл-сайты в `menu_state`/`ship_state` не трогаем, трек можно вернуть). Микс: всё
под `_master`, mute = `_master.gain = 0`.

## Как включается

Звук глобально не выключается кнопкой в UI — только `Mute/unmute` в дебаг-меню (кнопка `D`
слева сверху). **Первый клик по любой кнопке** (обычно `Play`) разблокирует `AudioContext`.

## Разблокировка звука (autoplay policy)

`AudioContext` до жеста пользователя стартует в `suspended`. `getAC()` создаёт контекст
лениво; первый реальный клик (`Sfx.click` из кнопки `Play`) вызывает `getAC()` → `resume()`.
Бэкап — одноразовый `window.addEventListener('pointerdown', getAC, {once:true})`.

## Точки интеграции

| Событие | Вызов | Файл |
|---|---|---|
| нажата любая кнопка | `Sfx.click()` | `ui.js` (`CreateButton`) |
| поставлена постройка | `Sfx.build()` | `ship_state.js` (`afterBuild`) |
| выстрел орудия игрока | `SfxShoot(fireKind)` | `ship_state.js` (`updateCombat`) |
| попадание по игроку | `Sfx.hit()` | `ship_state.js` (колбэк урона) |
| взрыв | `Sfx.explosion()` | `ship_state.js` (`spawnExplosion`) |
| смерть игрока | `Sfx.death()` | `ship_state.js` |
| локальный перелёт | `Sfx.jump()` | `system_travel_state.js` (`OnEnter`) |
| гиперпрыжок | `Sfx.hyperjump()` | `hyperjump_state.js` (`OnEnter`) |
| старт музыки | `MusicStart()` — сейчас no-op | `menu_state.js`, `ship_state.js` (`OnEnter`) |
| Mute/unmute | `ToggleMute()` | дебаг-меню (`DEBUG_GLOBAL`) |

Порядок подключения: `sound.js` идёт **сразу после `gl.js`** в `html/index.html` (нужны
только алиасы `Mr`/`Mmax`; `debug.js` подключается позже и видит `ToggleMute`).

## Бэклог

- **Вернуть музыку**, когда появится бюджет — амбиент или боевой вариант по `wasHostile`
  в `ship_state`. Помнить: стоит ~360 Б, `MusicStart`/`MusicStop` уже на месте как no-op.
- Разнообразие `Sfx.click` (лёгкая рандомизация частоты), отдельный звук на наведение/отказ
  постройки (нет металла).
- Финальная настройка параметров пресетов на слух / через jsfxr.
- `Tone`/`Noise` уже позиционные (было −224 Б). Дальше синт почти не ужать без потери
  эффектов — следующий срез размера в звуке = только повторный отказ от музыки/части SFX.
