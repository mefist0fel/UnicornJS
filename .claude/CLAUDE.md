# Unicorn — js13k project

Минималистичная 3D веб-игра для конкурса js13k (тема Unicorns and Rainbows). Жёсткий бюджет:
**весь zip-релиз ≤ 13 312 байт**. Каждый добавленный байт JS/CSS/разметки — это байт,
отнятый у геймплея. По умолчанию оптимизируй под размер и простоту, а не под
расширяемость/переиспользуемость — это одноразовый конкурсный проект, а не библиотека.

Документация — иерархическая, читай перед тем как менять архитектуру:

- [README.md](../README.md) — обзор и ссылки
- [docs/concept.md](../docs/concept.md) — концепт игры (не финальный)
- [docs/architecture.md](../docs/architecture.md) — стейт-машина, ECS-лайт, конвенции кода
- [docs/camera.md](../docs/camera.md) — орбитальная камера и её ограничители
- [docs/ui.md](../docs/ui.md) — DOM-панели/кнопки поверх WebGL
- [docs/build.md](../docs/build.md) — сборка/минификация/zip-бюджет

## Жёсткие правила

- **Без сторонних зависимостей.** Ни npm-пакетов, ни CDN, ни шрифтов/текстур с внешних
  доменов. Всё, что нужно игре, пишется руками или генерируется процедурно.
- **Без node.js для тулинга.** Сборочные скрипты — Python (stdlib) или .NET, см.
  [docs/build.md](../docs/build.md). Node/npm не устанавливать и не предлагать без явной
  просьбы пользователя.
- **Без ES-модулей и классов в игровом коде.** Файлы — плоские `<script>`, порядок
  подключения в `html/index.html` — единственный manifest сборки. Объекты — фабричные
  функции (`CreateXxx`), возвращающие объект-литерал, не `class`. Подробности и обоснование
  — [docs/architecture.md](../docs/architecture.md).
- **Не переусложнять ECS.** Компонент — это просто поле на плоском объекте-сущности,
  система — функция, проверяющая наличие полей. Не заводить реестр компонентов/архетипов.
- Стиль кода — без точек с запятой (ASI), `PascalCase` для функций, вызываемых из других
  файлов, `camelCase` — для локальных. Не обязательно к автоматической проверке, просто
  соблюдать при написании нового кода.
- UI — только через DOM-оверлей (`#ui`) с CSS `vmin`-размерами, не рисовать текст в WebGL.
  Ровно два виджета: текстовая панель и кнопка, см. [docs/ui.md](../docs/ui.md). Не
  добавлять новые типы виджетов без явного запроса — расширять существующие через CSS/props,
  а не плодить сущности.
- Любой хак (что-то нестандартное/неочевидное ради экономии байт) — фиксировать в
  соответствующем `docs/*.md`, не оставлять только в комментарии в коде.

## Соседний проект как референс организации

`../js13k_city` (Castle Wars JS) — предыдущий js13k-проект того же автора, использованный
как образец организации (стейт-машина, фабричные функции вместо классов, плоские глобали,
конкатенация + внешняя минификация). Смотреть туда за примерами стиля, но не копировать
их псевдо-3D canvas2d-рендерер — здесь настоящий WebGL, см. [docs/architecture.md](../docs/architecture.md).

## Тестирование

`html/index.html` открывается без сервера (`file://`), внешних ассетов нет. Для быстрой
проверки после правок — открыть в браузере и убедиться, что все 3 состояния (меню →
солнечная система → планета → назад) переключаются, камера упирается в ограничители, клик по
сфере планеты работает.
